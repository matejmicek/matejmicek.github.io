T/The thesis · 60 seconds

Three places money is being made.
Three where it isn't. Three open questions.

The stack is consolidating around three convergent ideas: verifiability is the moat (RL closes the loop wherever ground truth exists), minimal scaffolding (framework complexity collapses into the model as models improve), and MCP is the TCP/IP of agents (the protocol war is over; the next wave is auth, hosts, and security around it).

Where value is accruing
Durable orchestration (Temporal $5B). Inference systems (Baseten, Fireworks, Together, Lambda raised $2B+ combined in 12mo). Coding agents (Cursor $50B talks, Cognition $25B, Lovable $6.6B). Verticals already past $100M ARR (Sierra $15.8B, Harvey $11B, Decagon $4.5B).
Where it isn't
Pure agent frameworks (LangChain reframing as ops + traces). Pure vector DBs (Pinecone in M&A talks). Fine-tuning-as-a-SaaS (OpenPipe → CoreWeave; production fine-tuning declining per Braintrust data). LLM-only proxies without a strong wedge.
Open questions worth a check
MCP auth & enterprise governance. Agent payments (AP2, x402, Skyfire, Crossmint). RL environments & verifiable feedback infrastructure. Browser-identity / agent SSO. CEE-grown picks-and-shovels (E2B, Apify, Mistral, Lovable, Mastra, Dust).
  • Coding tools became their own asset class. Cursor at $29.3B (talks at $50B), Lovable $6.6B in 18mo, Replit $9B, Cognition $10.2B (talks at $25B), Factory $1.5B (5× in 7mo). Cursor's $2B ARR in 3 years is the new SaaS benchmark.
  • Inference is now picks-and-shovels. Cerebras IPO'd at $95B (May 14, 2026), CoreWeave public, Lambda $1.5B Series E, Crusoe $1.375B, Baseten $5B with 3 rounds in 12mo. Sovereign capital (Mubadala, GIC, QIA, DAMAC) deploying here alongside traditional VCs.
  • Big Tech's freeware threat is real. Google Jules (free background agent) + Gemini CLI (1,000 req/day free, 104k stars) + Agent Sandbox = vertically integrated stack undercutting commercial players on price.
  • Background & ambient agents are the new shape. Synchronous chatbots are giving way to long-running, event-triggered, bursty agents. This is what made durable orchestration (Temporal, Inngest, Trigger.dev) infrastructure-critical rather than nice-to-have.
  • MCP won the agent protocol war. OpenAI & Google adopted within 4 weeks; passed OpenAPI in GitHub stars 3 months ahead of projections. Boris Cherny (Anthropic) calls it "the answer." Next wave: registries (Smithery, Glama), hosting (Manufact), MCP-specific security (Backslash, Helmet).
  • Sovereign & non-traditional capital is flooding in. Qatar Investment Authority (xAI), GIC (Anthropic, Temporal, Harvey), Mubadala (Crusoe), DAMAC (Together), China National AI Fund (DeepSeek talks). Geopolitical-asset pricing.
  • CEE punches above its weight. Apify (Czech, Credo portfolio), E2B (Czech, 375× growth), Mistral (France), Lovable (Sweden), Dust (France), Mastra (TS framework), ElevenLabs (Polish founders — Credo first institutional check at $11B today). Most undermarketed angle in this map.

★/Cross-cutting themes from the practitioners

Nine threads through the stack.

Patterns that recur across multiple practitioner interviews — the ideas every layer is downstream of.

  • Verifiability is the moat. Karpathy + OpenAI Deep Research converge: RL closes the loop wherever ground truth exists. Whoever builds the verifiable environment for a domain owns the agents that operate in it.
  • Minimal scaffolding. Schluntz (Anthropic), Lopopolo (OpenAI Frontier), Neubig (OpenHands): as models improve, framework complexity collapses into the model. Durable infra survives — frameworks thin out.
  • Background / ambient agents are the new shape. Chase (LangChain), Abbas (Temporal), Polu (Dust): synchronous chat → event-triggered, long-running, bursty. Breaks every chatbot assumption.
  • Open ↔ closed model convergence at 7B–70B. Lin Qiao (Fireworks) + Latent Space year reviews: inference + customization become the moat once model quality converges.
  • MCP as TCP/IP for agents. Cherny (Anthropic), Soria Parra (MCP creator), swyx. Next wave: MCP auth, hosting, registries, security.
  • Human attention is the only non-parallelizable resource. Cherny, Lopopolo, Karpathy. The stack exists to maximize what one human can direct.
  • The training/inference split is permanent. Ross (Groq), Dean (Google), Lattner (Modular): NVIDIA owns training (HBM wins); inference is a multi-vendor cost-per-token + energy-efficiency market that NVIDIA has structural disadvantages serving.
  • Product-model co-design is the real coding agent moat. Nair (Cursor): RL doesn't generalize beyond training distribution. Companies with dense feedback loops (Cursor's 2-hour policy updates) win, not those with the best base model access. The agent runtime is the strategic asset, not the model weights.
  • "Fine-tuning is not a business" — automatic optimization is. Corbitt (OpenPipe → CoreWeave) + Goyal (Braintrust): production fine-tuning usage is declining. The durable layer is RL environments + reward infrastructure, not model customization as a SaaS.
